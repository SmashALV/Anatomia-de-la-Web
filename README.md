# Anatomia de la Web

This project is a web application built with Next.js to demonstrate and explore the fundamentals of web technologies.

## Prerequisites

Before you can run this project, you need to have Node.js and npm (or yarn) installed on your system.

-   **Node.js:** Download and install Node.js from [https://nodejs.org/](https://nodejs.org/). npm is included with Node.js.
-   **Yarn (optional):** If you prefer to use yarn, you can install it globally via npm: `npm install -g yarn`

## Installation

1.  Clone the repository:
```
bash
    git clone <repository-url>
    
```
2.  Navigate to the project directory:
```
bash
    cd <project-directory>
    
```
3.  Install the project dependencies. You can choose one of the following methods:

    -   Using npm:
```
bash
        npm install
        
```
-   Using yarn:
```
bash
        yarn install
        
```
## Running the Project

To start the development server, use one of the following commands:

-   Using npm:
```
bash
    npm run dev
    
```
-   Using yarn:
```
bash
    yarn dev
    
```
## Opening the Project

Once the development server is running, open your web browser and go to [http://localhost:3000](http://localhost:3000). You should see the project running there.

## Additional Notes

This project can be viewed on any device connected to the same network as the computer running the development server. Simply open a web browser on the other device and navigate to `http://localhost:3000`. Ensure the development server is running.
