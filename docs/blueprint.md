# **App Name**: Web Anatomy

## Core Features:

- Section Explorer: Display interactive examples of HTML sections (header, nav, main, article, aside, footer) with explanations of their purpose.
- Box Model Demo: Visually demonstrate the CSS box model (content, padding, border, margin) using interactive diagrams.
- CSS Function Preview: Provide a CSS property explorer with live previews of common CSS functions (display, position, flexbox, grid).

## Style Guidelines:

- Primary color: Light gray (#F0F0F0) for a clean background.
- Secondary color: Dark gray (#333) for text and headings.
- Accent: Blue (#3498DB) for interactive elements and highlights.
- Responsive layout adapting to different screen sizes.
- Use simple, clear icons to represent different HTML sections and CSS properties.
- Subtle transitions and animations to enhance interactivity.
